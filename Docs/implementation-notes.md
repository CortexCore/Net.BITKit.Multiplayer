# 实现说明（当前）

Unity 更新：共享 weaver 已移至 `Src/Editor/CodeGen/Weaver.cs`，实际 ILPP 与 Edit Mode Add/Read/UDP 已接通。当前宿主引用已补齐；PDB 生成新文件但未保留源行映射，Player/AOT 未验证。下列历史 .NET 设计边界结合 [当前状态](current-status.md) 和 [窗口记录](unity-editor-probe.md) 阅读。

先读 [当前状态](current-status.md)。本页是工程入口，历史性能数字在 [历史索引](history-index.md)，Unity 工作在 [接入手册](unity-integration-plan.md)。

- Runtime binding uses a weak object→explicit binding map only; each `RpcRuntime` owns target, pending, relay and state maps. The bridge is removed on unbind/dispose. `TargetKey` binds one object per runtime. Scope and peer session/epoch strings are caller-assigned; application must never reuse them for a newly admitted connection.
- Direct TouchSocket DMTP gameplay uses protocol flag 200 carrying generated **B6/v4** calls and bounded **B5/v3** control/state/replies; Relay uses its framing around opaque runtime data. Typed values use MemoryPack; old Runtime JSON is rejected. The Host maps verified physical sessions to externally authenticated PeerIds. VerifyToken is not account identity. Native UDP is the default packet implementation; HMAC/endpoint proof still sits above it.
- `ConfirmReady()` is an explicit application callback after admission; this slice does not implement a signed/network-negotiated ready acknowledgment. The Host's independently maintained member directory remains authoritative; clients cannot admit themselves at the Host merely by confirming locally.
- Host relay requires either a Host-bound service with explicit policy or `RegisterRelayPolicy` for a service hosted only at a peer. Receiver may additionally deny a client. Host authority maintains ready members and state. Snapshot requests are authorized by transport-bound membership. State is scalar/annotated DTO auto-property only; no SyncList/SyncDictionary.
- The weaver retains original method tokens, moves business bodies, and emits strongly typed wrappers/static receivers for both deliveries. Numeric IDs/fingerprints are generated; cold interface maps retain aliases. Binding reflects metadata and registers receiver delegates once; generated invocation does not call MethodInfo.Invoke. A marker rejects repeat weaving. The current file-based net10 tool does not emit symbols (PDB loss); extracting an Editor-compatible, symbol-aware transformation API is Unity adapter work. RpcTarget is routing metadata. Generic/open declaring types remain unsupported.
- Before first bind, woven SyncVar auto-setters perform local initialization without replication or authority checks; constructor assignments are allowed. On Host bind the current value seeds state, and on Client bind authoritative state supersedes local initialization when available. Bound Client writes fail, and detached instances reject setter/RPC/role-guard calls. Ordinary auto-property initializers may write backing fields directly and are likewise captured on Host bind.
- Only explicit `CallAsync<T>` accepts CancellationToken today; woven Task calls use runtime timeout and lifecycle completion. Timeout/cancel does not undo remote business work. Void is a notification: no application success reply, correlation waiter or fanout timer; receiver handler faults are receiver diagnostics. Actual pending sends may still retain borrowed buffers after a caller's wait ends. No automatic side-effecting RPC retries.
- Membership is a public read-only, versioned Host-owned directory. PlayerId/SteamId lookups resolve a unique ready peer. Joins/readiness/leaves replicate to clients; `RequestMembers()` explicitly resynchronizes. Demotion leaves the affected peer connected but unready and completes pending calls; Host re-ready restores it. Removal sends a terminal revocation, clears its client directory, and makes it logically disconnected; application teardown must still dispose the physical socket. IDs retired in a scope cannot be readmitted; applications assign fresh room epochs and Peer IDs. Admission and ready acknowledgment are still application responsibilities.
- Lifecycle and SyncVar state mutations are coordinated with runtime/per-binding locks; concurrent unbind/dispose/write tests pass. This protects runtime bookkeeping, not arbitrary user business methods: services must choose their own execution serialization or a future Unity main-thread scheduler. `Unbind` retains state for the same logical identity; `RemoveTarget` permanently tombstones the identity within the scope and notifies all admitted peers, including unready peers and RPC-only bindings. Versioned directory snapshots carry these bounded tombstones for later admissions.
- Runtime uses registered MemoryPack value schemas with bounded binary preflight, never remote CLR type-name binding. Core has no Newtonsoft/JToken dependency. Members, targets, buffered state, requests, relays and fanout are bounded. State reading uses the explicit authorization method key `$sync.state`; do not assume an RPC write policy automatically grants all clients state visibility. Reliable generated DTOs require explicit contiguous MemoryPackOrder; see [binary migration](reliable-binary-guide.md).
- Core builds C#9/netstandard2.1 with MemoryPack.Core and DI.Abstractions; native Transport and TouchSocket adapter build netstandard2.1/net8.0. Current UPM metadata does not resolve these dependencies: Runtime asmdef references are empty, Transport has no asmdef, and TouchSocket asmdef has not yet declared Transport. UPM import/ILPP/UniTask/AOT remain unverified. CodeGen/tests stay outside Src and must not be copied into a Runtime assembly.

- `IRoomMemoryWire` is selected instead of the legacy byte[] event; Direct receives borrowed memory, Relay asynchronous mailboxes own bounded pooled frames. A send frame cannot be returned until the underlying IO completes, including failure/close. Current generated 0 B assertions are for warmed synchronous scalar/fixed-struct tests, not every array/DTO or real transport operation.
- `RpcCallContext.TryGetValue` uses the synchronous value view; the old Current class view may allocate. Nested async/sync contexts track the async parent so one call cannot read another target's context. `AuthorizationRequest` is a readonly struct.
- `TypedRpcHeader` is numeric and readonly; the old `Packet` class remains for v3 control/reply/compatibility. There is no Host-pushed method catalog yet. Do not mistake a schema fingerprint check for dynamic protocol synchronization.
